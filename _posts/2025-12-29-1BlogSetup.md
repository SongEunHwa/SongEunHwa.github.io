##### 1. _data/navigation.yml 설정

```yaml
main:
  - title: "Category"
    url : /categories/
  - title: "tag"
    url : /tags/
  - title: "Search"
    url: /search/

docs:
```

상단에만 Category / tags / Search 3개의 카테고리를 두고

Category를 선택시에 모든 Category를 확인할 수 있도록 한다.

Category 클릭 -> /categories/ -> _pages/category_archive.md 가 렌더링

##### 2.  _pages/category_archive.md 설정

```yaml
---
title: "Category"
layout: categories
permalink: /categories/
author_profile: true
sidebar_main: true
---
```

카테고리 목록 페이지(category_archive.md) : 특정 카테고리를 전부 보여주고 연결되도록 하기.

##### 3. pages/categories/categories-(이름).md

```yaml
---
title: "(이름)"
layout: archive
permalink: categories/(이름)
author_profile: true
sidebar_main: true
---

{% assign posts = site.categories.(이름) %}
{% for post in posts %} {% include archive-single2.html type=page.entries_layout %} {% endfor %}
```

(이름)에 해당하는 카테고리를 선택시에 (이름) 카테고리와 매칭된 모든 글들을 나열시켜 목록을 보여준다.



------

#### 사이드바 카테고리 + 글 수 표시 구현

이 구조는 아래 글을 참고하여 구현하였다.
- 참고: https://xubxn.github.io/blog/category/

  

##### 4. _includes/sidebar.html

```yaml
  {% if page.sidebar_main %}
    {% include nav_list_main %}
  {% endif %}
```

sidebar_main: true인 페이지에선 nav_list_main을 불러온다.



##### 5. _incluldes/nav_list_main

상세 코드 내용은 참고 페이지를 확인 바람.

```html
        <span class="nav__sub-title">(대분류이름)</span>
            <ul>
                {% for category in site.categories %}
                    {% if category[0] == "(이름)" %}
                        <li><a href="/categories/(이름)" class="">(이름) ({{category[1].size}})</a></li>
                    {% endif %}
                {% endfor %}
            </ul>
```

원하는 대분류의 이름과 카테고리의 이름을 알맞게 기입
